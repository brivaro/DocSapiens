# 🚀 DocSapiens: RAG Portal for Businesses
A high-performance Retrieval-Augmented Generation (RAG) platform designed to help businesses transform unstructured documents into actionable, AI-powered insights.
Seamlessly integrates frontend + backend to manage, vectorize, search, and chat with your internal data.

## 🧠 Features
 * 🔍 Document ingestion & vectorization (PDF, DOCX, TXT, etc.)
 * 💬 Chat with your data via LLMs (OpenAI / Google / open-source)
 * 🧾 Full-text + semantic search with hybrid retrieval
 * 🛡️ Secure API & frontend access control
 * 📊 Scalable backend for enterprise use

## 🛠️ Tech Stack
 * FastAPI · PostgreSQL · LangChain · Qdrant 
 * React / Next.js frontend
 * Docker / CI/CD ready

## 💼 Ideal for
 * ✅ Internal knowledge portals
 * ✅ Customer support automation
 * ✅ Legal, finance, and HR document analysis
 * ✅ Private GPTs for business intelligence
